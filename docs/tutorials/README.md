# Tutorials

[Documentation home](../README.md)

Follow these exercises in order. Each has a concrete outcome, complete inputs, and observable checkpoints. You can stop after any tutorial with a working application.

1. [Your first application](first-application.md): install PCVMF, run synthetic vision, inspect output, and complete a finite run.
2. [Your first vision plugin](vision-plugin.md): create an installable package and load a pipeline without editing the framework.
3. [Combine vision and temperature](multiple-sensors.md): route two publishers to one typed-message controller.

If you already know the framework and need to solve one problem, use the [how-to guides](../how-to/README.md).
